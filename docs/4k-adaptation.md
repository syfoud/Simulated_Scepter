# 4K（3840×2160）适配

本次社区贡献新增适配的范围仅为 Windows 本地游戏 **3840×2160**。游戏设置中必须**关闭 DLAA 和抗锯齿**，继续关闭 HDR、使用简体中文并保持游戏在前台且无遮挡。程序不会代替用户修改这些画质设置。

原有 1920×1080、云游戏的 1080p 边框容差及单轴为 1080p 的居中裁剪行为保留。不新增 2560×1440、其他 16:9 分辨率或 4K 云游戏支持，也不承诺任意系统缩放比例均已验证。

## 实现与使用

- GUI 在 Qt、截图及键鼠模块初始化前设置进程 DPI 感知。三个模式共用物理像素窗口几何，截取 4K 画面后用 `INTER_AREA` 缩至 1920×1080，继续使用既有识别坐标和模板。
- 点击、拖动和滚动位置按横纵轴映射回物理坐标。差分宇宙仅在本地全屏保留原有 9 像素补偿，云游戏不使用该补偿。
- 4K 模板匹配增加亚像素补偿，重复数字逐位置匹配；保留原有阈值及 1080p 路径。补充重投／作弊次数字形和最小真实图像回归样本。
- 小地图方向低可信、定位失败、截图失败、窗口失焦／移动／改变大小时停止当前不可靠操作并释放输入。窗口位置或尺寸变化后需停止并重新启动任务，以重新取得截图与输入几何。
- 停止先终止移动和地图线程、释放输入，再关闭截图资源。录像切段与停止串行处理；慢速编码线程未退出时不提前释放写入器或启动新录像，超时会明确报错并保留视频。
- 修复审阅中发现的路径拼接错误，使地图备份和恢复使用同一目录，并纠正差分 OCR 的配置路径；保留上游已有角色、策略及录像保留规则。

## 实机验收边界

历史开发中采集了 3840×2160、175% 系统缩放的游戏图像，本 PR 保留必要的 HUD／小地图裁剪用于回归。它们来自此前版本，不能替代本次贡献分支的实机验收。

本次尚未完成最终分支的真实游戏端到端验证，包括 1080p 基线、4K 的实际鼠标命中、进图／传送／战斗／棋盘、三种模式、失焦／移动／停止以及持续运行。DLAA 和抗锯齿关闭时的最终效果仍需实机确认；自动化测试通过不表示已完成这些检查。PR 以草稿提供社区审阅，不预设维护者接受或合并。
