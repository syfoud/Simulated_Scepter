## 本轮面具流程

从 Mask-Selection 第1或第3张所示的未选面具界面运行：

```powershell
& 'E:\srironblood\Simulated_Scepter\.venv\Scripts\python.exe' 'E:\srironblood\Simulated_Scepter-divine-treasure\divine_treasure_entry.py' --run --stage masks
```

启动后5秒内切回游戏。优先雪鸮面具；没有则按可见额度刷新一次；仍没有则选一个非点子王普通面具完成开局，并在首区结束结算。若拿到雪鸮，任选中央方程，领取祝福，再筛选首次惊世奇迹。

开局惊世奇迹接受绽、解、霸，出现任意一项就选择；超需面具8级后出现，不在开局目标中。未命中时，在选卡前使用下方重随，最多3次；每次必须确认剩余次数减少才处理新结果，允许连续重随出同一张卡。次数耗尽仍未命中，则选择当前奇迹完成入局，再结束并结算。

未获得雪鸮或开局目标奇迹时，结算返回首页后自动进入下一把；获得雪鸮及目标奇迹后停在首个战斗区域，不移动角色。整次命令仍受240秒总上限约束，重开不会重置上限。

用户已实机确认面具选择及未获得目标面具时的结算重开正常，批准作为正式代码保留。`--stage opening` 可连接正式入场和该流程；整段联跑未单独确认。

| 样本 | 识别与动作 |
| --- | --- |
| 1–3 | 读取三个面具和刷新额度，选择雪鸮或刷新；额度耗尽时选普通面具用于结算 |
| 4–5 | 核对右侧所选面具后确定；核对获得结果后关闭 |
| 6–8 | 选择中央方程，确认按钮激活后确认，关闭获得祝福结果 |
| 9–10 | 确认只有一个惊世奇迹；雪鸮开局未命中绽/解/霸则重随，至多3次；命中或次数耗尽后选卡确认 |
| 11 | 雪鸮且目标奇迹命中时成功停止；其他情况按 Esc 结算 |
| 12–15 | 结束并结算 → 确认 → 返回主界面 → 进入下一把 |

样本中“雪鸮”被 OCR 读作“雪鸡”，实现兼容已观察到的别名。方程与奇迹确认按钮通过对应页面锚点及样本选中前后的底色差异判断。多选奇迹、无法读取刷新或重随额度、奇迹名称不明、面具不一致或页面超时均停止并保留日志，不把识别失败当成重开条件。
