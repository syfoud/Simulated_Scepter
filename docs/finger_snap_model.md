## 1. 问题设定

### 1.1 三位面串联结构

游戏共三张地图（位面 1、2、3），首尾相连，顺序通关：

$$\text{位面1} \longrightarrow \text{位面2} \longrightarrow \text{位面3}$$

玩家持有全局资源：$C$ 次 cheat、$R$ 次 reroll，三张图共享。在位面 $k$ 消耗 $(c_k, r_k)$ 后，剩余 $(C - \sum c_k, R - \sum r_k)$ 留给后续位面。

### 1.2 位面的双重性质

| 性质 | 含义 |
|------|------|
| **尺度固定** | 每张图的 DAG 最长路径步数 $S_k$ 是固定的。位面 1/2/3 各有其典型 $S_k$ |
| **布局不定** | 具体节点类型（reward/battle/event/elite/...）、连接关系、传染节点分布随每局生成而变化 |

这意味着一局中实际遇到的三张图与"典型图"不同，但尺度（步数上限）一致。因此：

> **资源分配策略需要从典型图估算边际价值，再在实际图中使用。**

### 1.3 典型图

| 位面 | 典型图文件                 | 用途 |
|------|-----------------------|------|
| 1 | `20260620_114926.png` | 估算位面 1 的 W 表 |
| 2 | `20260620_115208.png` | 估算位面 2 的 W 表 |
| 3 | `20260620_115639.png` | 估算位面 3 的 W 表 |

典型图提供各图 **W 表**（资源→期望 CD 增益的映射），供跨图资源分配使用。实际图分析时复用该 W 表构建 future table，无需每局重新估计。

## 2. 核心架构：三层价值函数

整个优化器围绕三层递进的价值函数构建，按**从后往前**的顺序计算：

| 层级 | 函数 | 输入 | 输出 | 求解器 | 计算顺序 |
|------|------|------|------|--------|----------|
| L1 单步 | $Q_{\text{eff}}$, $Q_{\text{path}}$ | $(n, M, c, r, e)$ | 效果决策 / 路径选择的终局 CD | MC ε-greedy | 第三步 |
| L2 单图 | $W_k(c, r)$ | 资源量 $(c, r)$ | 在位面 $k$ 的**本地**期望 CD | MC 估计 → 双线性插值 | 第一步（无 F） |
| L3 跨图 | $F(c, r)$, $B_k(c, r)$ | 分配给后续图的资源 | 后续图的总最优 CD | DP 二维背包合并 | 第二步（由 W 合并） |

**依赖关系**（无循环）：

$$\text{第一步: } W_1, W_2, W_3 \text{ 独立估计（future\_table = \{\}）}$$
$$\text{第二步: } F_2 = \text{merge}(W_3),\; F_1 = \text{merge}(W_2, W_3)$$
$$\text{第三步: L1 MC/DP 使用 } F \text{ 作为终端条件}$$

$W_k$ 始终只包含位面 $k$ 的本地 CD，$F$ 由 $W$ 相加合并而来。$W$ 在第一步就算好了，后续不再修改。不存在 $W \to F \to W$ 的回环。

## 3. 单步模型（L1：Monte Carlo 控制）

### 3.1 状态空间

$$\text{CountdownState} = (n, M, \text{cd}, c, r, \text{locked}, e_{\text{lock}}, \text{skip})$$

| 符号 | 含义 |
|------|------|
| $n$ | 当前节点索引 |
| $M \in \{0,1\}^N$ | 感染位掩码 |
| $\text{cd}$ | 当前倒计时 |
| $c, r$ | 剩余 cheat / reroll |
| $\text{locked}$ | 效果是否已锁定（跳过效果决策） |
| $e_{\text{lock}} \in \{1..6\}$ | 已锁定的效果（-1=未锁定） |
| $\text{skip}$ | 是否跳过效果应用（效果已在感染区中反映） |

**CD 线性可加性**：

$$V(n, M, \text{cd}, c, r) = \text{cd} + W(n, M, c, r)$$

这一简化将 DP 状态空间从 $\text{cd}$ 维度解耦。

### 3.2 六种效果

| 编号 | 名称 | 感染变化 | CD 变化 | 自动/手动 |
|------|------|---------|---------|-----------|
| 1 | 浇灌 (SPREAD) | 每感染节点随机传染一邻居 | 0 | 自动 |
| 2 | 为善 (BONUS) | 无 | +（活跃感染节点数） | 自动 |
| 3 | 对症 (ADJACENT) | 感染下一节点的所有邻居 | 0 | **手动** |
| 4 | 慈怀 (SELECT) | 手动选一个节点感染 | 0 | **手动** |
| 5 | 归心 (RANDOM_INFECT) | 随机感染一个未感染节点 | 0 | 自动 |
| 6 | 可憎 (NOTHING) | 无 | 0 | 自动 |

$\mathcal{A}_{\text{auto}} = \{1, 2, 5, 6\}$：观察到即自动结算。对症(3)和慈怀(4)需人工选择目标。

### 3.3 单步动作与转移

**效果决策**：

$$\mathcal{A}_e(c, r) = \{\text{keep}\} \cup \{(\text{cheat}, k) \mid k=1..6,\; c>0\} \cup \{\text{reroll} \mid r>0\}$$

**路径选择**：$\mathcal{A}_p(n) = \text{edges}[n]$（当前节点的出边列表）

**转移**（以锁定效果 $e$，选择下一节点 $n'$）：

1. 应用效果：$(M_e, \Delta_{\text{eff}}) = \text{apply\_effect}(M, e, n', D(n'))$
2. 移动：$\Delta_{\text{move}} = +1$ 若 $M_{n'}=1$，否则 $-3$
3. 列销毁：$M' = M_e \setminus D(n')$，其中 $D(n') = \{i : \text{col}(i) \le \text{col}(n')\}$
4. 新状态：$\text{cd}' = \text{cd} + \Delta_{\text{eff}} + \Delta_{\text{move}},\; c' = c - \text{cost}_c$

### 3.4 MC 双 Q 表

**Q 表的实际结构**

Q 表不是传统强化学习的值函数近似，是**纯 Monte Carlo 样本池**——字典嵌套字典，叶子是终局 CD 的滑动窗口列表。

**$Q_{\text{eff}}$（效果决策 Q 表）** — 三层嵌套字典：

```
Q_effect[ ((n, M, c, r), e_obs) ][ action_key ][样本列表]
                                              ├── ('keep',):    [cd₁, cd₂, ...]  ← 滑动窗口 ≤200
                                              ├── ('cheat', k): [cd₁, cd₂, ...]  ← k=1..6, c>0 时存在
                                              └── ('reroll',):  [cd₁, cd₂, ...]  ← r>0 时存在
```

**$Q_{\text{path}}$（路径选择 Q 表）** — 三层嵌套字典：

```
Q_path[ ((n, M, c, r), e_locked) ][ n' ][样本列表]
                                    └── 下一节点索引: [cd₁, cd₂, ...]
```

**叶子列表的含义**：每次 MC rollout 走到终点时，记录终局 CD，追加到该局沿途每个被访问的 Q 条目尾部；若列表长度超过 200，`pop(0)` 丢弃最旧样本。

**Q 表如何被查询**：所有决策都取叶子列表的**算术均值**作为该动作的期望值：

$$\bar{Q}[(\text{state}), \text{action}] = \frac{1}{\text{len(list)}} \sum \text{list}$$

这就是为什么文档中写法是 $Q_{\text{eff}}[\cdots][\cdots] \to [\text{cd}_{\text{final}}, \dots]$——箭头右边不是标量，是样本列表。

**为什么是纯 MC 而不是 Q-learning**：没有 TD 误差、没有 Bellman 回溯、没有 bootstrapping。每个样本就是一次真实走完的终局 CD。这避免了函数近似和自举带来的偏差，代价是需要大量 rollout 以减少方差。

更关键的区别：**样本之间没有经验学习**。旧样本被 `pop(0)` 直接丢弃，不做经验重放；新样本不通过 TD 误差与旧样本产生关联；所有 `(state, action)` 条目完全独立，相邻状态之间不共享信息。唯一的"进步"来自策略自身的改善——随着 Q 估计收敛，新 rollout 的行为质量提高，产生更高终局 CD 的新样本逐步替换旧的低值样本。这不是样本之间的学习，是策略迭代的副产品。

**训练过程**：ε-greedy MC 控制，默认运行 **15000 局**。每局从起点走到终点，沿途每个 `(state, action)` 将其终局 CD 追加到对应 Q 条目列表中；超过 200 条时丢弃最旧的。贪心决策时取列表算术均值。

**滑动窗口的局限**：窗口限制使每个 Q 条目至多保留 200 个样本，无论训练局数多少。其后果：
- ε 恒为 0.3 不衰减，新样本和旧样本中都有 30% 来自随机探索，噪声水平不随训练减少。
- 稀有状态（如特定感染掩码组合）可能几十局才被访问一次，其"最近 200 条"实际跨越数千局，大量来自早期低质量策略。
- 早期探索中偶然发现的好结果，若之后 200 次访问该条目时均未复现，会被静默丢弃。
- 跑 15000 局 vs 5000 局，对频繁状态的 Q 值方差无改善（都被窗口钳制在 200）——更多 rollout 只增加状态覆盖率，不降低已有状态的估计误差。

**贪心效果选择** $\text{greedy\_effect}(sk, e_{\text{obs}})$：

$$\text{keep\_score} = \overline{Q_{\text{eff}}}[(sk, e_{\text{obs}})][\text{'keep'}]$$

$$\text{cheat\_score}(k) = \overline{Q_{\text{eff}}}[(sk, k)][\text{'keep'}] - \gamma_c$$

$$\text{reroll\_score} = R_{\text{mc}}(sk) - \gamma_r$$

其中 $\gamma_c = \max(F[(c,r)] - F[(c-1,r)],\; 0.02)$，$\gamma_r = \max(F[(c,r)] - F[(c,r-1)],\; 0.02)$。

$\gamma$ 的含义是资源的**边际未来成本**（从 future table 查得，见第 5 节）。0.02 是底线值，没有严格的推导——它既不是有效的噪声过滤器（MC 标准误 ~0.35，0.02 只有其 1/17），也不是真正的机会成本（Plane 3 和 W 估计阶段没有下家，真实边际成本为 0）。实际决策中两个动作的 Q 值差异通常远大于 0.02（CD 为整数和，差异至少在 0.5 以上），因此 0.02 不会实质性地翻转任何决策。它的存在纯粹是工程习惯——防止 $\gamma$ 恰好为 0 的一个任意小的正数。

**Reroll 估值** $R_{\text{mc}}(sk)$：自底向上递推

$$\text{keep\_at}(rp, e) = \text{Q\_effect}[(n, M, c, rp, e)][\text{'keep'}]$$

$$R_{\text{mc}}[rp] = \min\!\Bigg(\frac{1}{6}\sum_{e=1}^{6} \max\!\big(\text{keep\_at}(rp, e),\; R_{\text{mc}}[rp-1]\big),\; \max_e \text{keep\_at}(rp, e)\Bigg)$$

$$R_{\text{mc}}(sk) = R_{\text{mc}}[r]$$

每层 $rp$ 从该层资源水平 $(c, rp)$ 的 Q 表中读取 keep 值，并封顶于同层的最大 keep 值。递推回退时若某 rp 层 Q 数据不足，回退到原始 $r$ 层数据。"$\text{keep\_at}(rp, e)$" 明确标注了该值来自哪一资源层，避免跨层封顶导致的不一致。

## 4. 单图模型（L2：W 表估计）

### 4.1 W 表定义

$$W_k(c, r) = \mathbb{E}[\text{在位面 } k \text{ 的终局 CD} \mid \text{初始 CD}=0,\; \text{资源 } (c, r)]$$

这不是"CD 增益"而是**终局 CD 的期望值**（相对初始 CD=0）。$W_k(0, 0)$ 是纯步行基线（可能为负，因为未感染步 -3 惩罚）。

**关键约束——资源封顶**：

- **Cheat** 每步至多消耗 1 次（指定效果后决策阶段结束，不得再次 cheat），因此 $c_k^{\max} = S_k$。
- **Reroll** 消耗后仍在同一步的决策阶段内，可连续重投直到满意或用尽次数，**不受步数约束**。$r_k^{\max}$ 由玩家实际持有的 reroll 次数（或 DP 计算上限 30）决定，与 $S_k$ 无关。

### 4.2 估计流程

W 表不是从 Q 表代数推导的，而是**用 Q 表作为策略控制器**，反复跑仿真取终局 CD 均值。整个过程分为四步。

**第一步：MC 训练，生成 Q 表**

以最大资源 `(max_cheat, max_reroll)` 跑 ε-greedy MC 控制（默认 15000 rollouts），每局终局 CD 为纯本地值（`state.countdown`，不附加 future_table）。训练只产出一份 Q 表，但 rollout 中资源自然从最大值消耗到零，同一份 Q 表覆盖了 `{(n, M, c, r) : 0 ≤ c ≤ max_cheat, 0 ≤ r ≤ max_reroll}` 的全部资源水平。

**W 表估计时没有 future_table**：此阶段 $F \equiv 0$，真实的边际成本应为 0（资源没有下家）。代码中 $γ$ 退化为底线 0.02 而非 0，这是工程实现上的一个偏差（见 3.4 节对 0.02 的说明），没有理论依据。实际影响可忽略——CD 差异量级远大于 0.02，不影响 W 表估计结果。

**第二步：纯贪心仿真，采样 W(c, r)**

对每个采样点 `(c, r)`，以该资源量初始化状态，跑 300 局纯贪心仿真。每局流程：

$$\text{初始状态}(c, r) \xrightarrow{\text{greedy\_effect}(Q_{\text{eff}})} \text{锁定效果} \xrightarrow{\text{greedy\_path}(Q_{\text{path}})} \text{移动到 } n' \xrightarrow{\text{apply + destroy}} \cdots \xrightarrow{} \text{终端}$$

$$\text{终局值} = \text{state.countdown} + \text{future\_table}[(c_{\text{rem}}, r_{\text{rem}})]$$

$$W(c, r) = \frac{1}{300} \sum_{i=1}^{300} \text{终局值}_i$$

**为什么要关闭探索（ε=0）**：训练阶段 ε=0.3 是为了发现好的策略。W 表是用来衡量"这个策略到底能打多少分"。如果评估时还开着 30% 随机探索，测出来的是 70% 最优策略 + 30% 乱走的混合成绩，低估了策略的真实能力。玩家实战中不会随机探索——关闭探索的评估结果才对应玩家按下最优决策后的实际 CD 期望。

**资源如何在仿真中体现**：W(c, r) 中不同的 `(c, r)` 输入并非直接参与计算，而是作为仿真的**开局条件**——每局以恰好 `c` 次 cheat、`r` 次 reroll 起步。仿真过程中，贪心决策器在每一步做带成本的比较：

$$\text{选最高分: } \max\big(\text{keep\_score},\; \max_k \text{cheat\_score}(k),\; \text{reroll\_score}\big)$$

$$\text{cheat\_score}(k) = \overline{Q_{\text{eff}}}[(\text{keep } k)] - \gamma_c,\quad \gamma_c = \max(F[(c,r)] - F[(c-1,r)],\; 0.02)$$

$$\text{reroll\_score} = R_{\text{mc}}(sk) - \gamma_r,\quad \gamma_r = \max(F[(c,r)] - F[(c,r-1)],\; 0.02)$$

$\gamma_c$ 和 $\gamma_r$ 是资源的**边际未来成本**——来自 L3 跨图分配，回答"这个资源留给后续位面值多少 CD"。典型情况：
- 位面 3 终局前：$F \equiv 0$，真实边际成本为 0（无下家），$\gamma$ 退化为底线 0.02
- 位面 1 第一步：$\gamma$ 由 F 表差值决定（后面还有两个位面），数值较大，非显著优势不浪费

资源消耗由每一步的成本收益比较决定，不是"有就用"。300 局仿真中资源的使用时机、数量、分布全由 Q 表和 future table 共同约束，W 表只记录终局结果。

**第三步：双线性插值，补全网格**

采样网格是稀疏的——低资源密集 `c ∈ [0..5]`, `r ∈ [0,1,2,3,5]`，高资源稀疏 `c ∈ [8,12,max]`, `r ∈ [10,20,50,max]`。对未采样的 `(c, r)`，用包围它的四个采样角点做双线性插值：

$$W(c, r) = w_{00}(1 - t_c)(1 - t_r) + w_{10} \cdot t_c(1 - t_r) + w_{01}(1 - t_c)t_r + w_{11} \cdot t_c \cdot t_r$$

其中 $t_c = (c - c_{lo})/(c_{hi} - c_{lo})$, $t_r = (r - r_{lo})/(r_{hi} - r_{lo})$。

**第四步：缓存**

W 表以 JSON 存入缓存文件（按图像哈希 + 参数哈希命名），后续同图分析跳过训练直接加载。

### 4.3 W 表含义示例

| 资源 | W 值 | 解读 |
|------|------|------|
| $W(0,0) = -2.5$ | 不用资源，纯步行期望终局 CD = -2.5（净损失） |
| $W(1,0) = +0.3$ | 用 1 cheat → 期望 CD = +0.3（扭亏为盈） |
| $W(0,1) = -1.8$ | 用 1 reroll → 期望 CD = -1.8（改善但未盈利） |
| $W(5,5) = +8.0$ | 充分资源 → 大幅盈利 |

$W(1,0) - W(0,0) = +2.8$ 是第 1 个 cheat 在此图的边际价值。这正是 future table 中 $F[(c,r)] - F[(c-1,r)]$ 的来源。

## 5. 跨图模型（L3：资源联合分配）

### 5.1 Future Table：后续地图的资源价值

已知后续地图的 W 表序列 $W_{k+1}, W_{k+2}, \dots, W_m$，定义：

$$F_k(c, r) = \max_{\sum c_i = c,\; \sum r_i = r} \sum_{i=k+1}^{m} W_i(c_i, r_i)$$

即：留 $(c, r)$ 资源给后续所有地图，最优分配下的**总期望 CD**。

### 5.2 构建算法

Future table 是 W 表的**二维背包合并**。从最后一张图开始，逐张向前合并 W 表。

**算法**（对应 `build_future_table`）：

```
输入: [W_3, W_2]  （位面 1 的"后续图 W 表序列"，即位面 2 和 3 的 W 表）
输出: F_1(c, r) = "留 (c, r) 给位面 2+3，最多能换多少 CD"

步骤:
  F = W_3                              ← 从最后一张图开始
  对于 W_2:
    新表 F' = {}
    对每个 (c, r) in [0..max_cheat] × [0..max_reroll]:
      best = 0
      对每种分配给 W_2 的量 (c2, r2):
        对每种分配给 F(原位面 3) 的量 (c3 = c-c2, r3 = r-r2):
          val = W_2(c2, r2) + F(c3, r3)
          best = max(best, val)
      F'[(c, r)] = best
    F = F'                             ← 合并完毕
```

合并的每一步遍历所有资源分配组合，找最优。例如 $F_1(2, 3)$ 表示"2 cheat + 3 reroll 分给位面 2 和 3，最优能拿多少 CD"——它枚举 (c2=0,r2=0,c3=2,r3=3)、(c2=0,r2=1,c3=2,r3=2)、……(c2=2,r2=3,c3=0,r3=0) 共 $(2+1)\times(3+1)=12$ 种分法，取最大。

**计算复杂度**：$O(m \cdot C^2 \cdot R^2)$，对典型参数（$C \le 25, R \le 150$）在秒级完成。

**资源封顶的作用**：合并时查询 W 表超出其 $S_k$ 封顶的 $(c, r)$，取封顶值而非 0.0。因为给某图分配超过其步数的资源虽然无用，但不会消失——多余的可以留给后续图。若错误地返回 0.0，合并结果会低估 F 表值。

### 5.3 联合分析（反向归纳）

F 表是中间产物。最终的资源分配方案由**反向归纳**（`analyze_joint_maps`）给出：

从最后一张图开始向前递推，对每位面 k 和每种剩余资源 $(c, r)$，枚举本图使用量 $(c_u, r_u)$，最大化：

$$B_k(c, r) = \max_{c_u, r_u} \Big[W_k(c_u, r_u) + B_{k+1}(c - c_u, r - r_u)\Big]$$

其中 $B_{m+1}(\cdot) = 0$。$B_1(C, R)$ 即全程最优总期望 CD。

**输出**：
- $(c_1^*, r_1^*), (c_2^*, r_2^*), (c_3^*, r_3^*)$：每位面应该花多少资源
- 累计 CD 阈值检查：$\text{cum\_cd}_k \ge \text{threshold}_k$
- 总期望 CD：$\text{initial\_cd} + B_1(C, R)$

### 5.4 Future Table 如何反馈到 L1

Future table 通过四条路径影响单步决策：

1. **终端节点估值**：DP 中 $W_{\text{terminal}} = F(c, r)$，使得"留资源给未来"有价值
2. **Episode 终值**：MC rollout 结束时的 CD 加上 $F(c_{\text{rem}}, r_{\text{rem}})$
3. **边际资源成本**：$\gamma_c = F[(c,r)] - F[(c-1,r)]$，$\gamma_r = F[(c,r)] - F[(c,r-1)]$，用于贪心决策中惩罚资源消耗
4. **DP 求解**：`dp.solve(future_table=F)` 在整个反向 DP 中使用 future table 作为终端条件

这四条路径共同确保：**在位面 1 消耗 1 个 cheat 的决策，会考虑该 cheat 在位面 2、3 的潜在价值。**

## 6. 精确动态规划（ExactCountdownDP）

### 6.1 W 与 V 的定义

$$W(n, M, c, r) = \frac{1}{6} \sum_{e=1}^{6} V(n, M, c, r, e)$$

$$V(n, M, c, r, e) = \max\begin{cases}
\displaystyle\max_{n' \in \text{edges}[n]} \big[\Delta_{\text{eff}} + \text{move\_delta} + W(n', M', c, r)\big] & \text{(keep)} \\[12pt]
\displaystyle\max_{k=1..6,\;c>0} \max_{n' \in \text{edges}[n]} \big[\Delta_{\text{eff}}(k) + \text{move\_delta} + W(n', M', c-1, r)\big] & \text{(cheat)} \\[12pt]
W(n, M, c, r-1) & \text{(reroll, } r>0 \text{)}
\end{cases}$$

### 6.2 按 r 分层递推

reroll 值依赖 $W(n, M, c, r-1)$，因此必须按 $r = 0, 1, \dots, r_{\max}$ 递推。每层 $r$ 处理全部节点（拓扑逆序），确保 $W(\cdot, \cdot, \cdot, r-1)$ 已计算完毕。

### 6.3 资源外推

DP 精确求解 $c \le 5, r \le 30$。超出部分：

$$W(n, M, c, r) = W(n, M, \min(c, 5), \min(r, 30))$$

假设超出精确范围后资源边际收益为 0。

### 6.4 W_best（最优极限）

与 W 计算相同，但随机效果（归心/浇灌）取 $\max_{outcomes}$ 而非期望。用于 `trace_best_path` 展示 DP 理论最优路径。

### 6.5 终端条件

$$W(n, M, c, r) = F(c, r) \quad \text{当 } n \text{ 为终端节点}$$

非零 future table 使终端节点的 W 值非零，这是"留资源给未来"在 DP 中的核心机制。

## 7. 完整流水线

### 7.1 run_full_analysis（离线分析）

```
输入: 三张典型图, max_cheat, max_reroll, thresholds
输出: 每图 W 表 + 联合资源分配方案 + MC 评估

Pass 1 (L2): 对每张典型图
  1. 图像 → 节点/边/传染/起点
  2. DAG 最长路径 → 步数 S_k = 资源封顶
  3. MC.estimate_w_table() → W_k[(c, r)]

Pass 2 (L3): 
  4. build_future_table(后续图W表) → F_k
  5. analyze_joint_maps(所有W表) → 最优分配 (c_k*, r_k*)

Pass 3 (L1+L2+L3): 对每张图
  6. DP 热启动 (含 future_table)
  7. MC 训练 (含 future_table)
  8. MC 评估 + 策略推荐
```

### 7.2 analyze_single_map（在线单图分析）

```
输入: 单张当前地图图像, cheat, reroll, future_table, ...
输出: 该图的 MC 策略 + DP 分析 + 首步推荐

1. 图像 → 节点/边/传染/起点
2. W 表缓存命中? → 跳过
3. DP 求解 (含 future_table) → 热启动 MC
4. MC 训练 (含 future_table)
5. 评估 + 决策分析 + 推荐首步
```

**在线使用场景**：玩家在实际游戏中截取当前位面的地图，`analyze_single_map` 结合预计算的 `future_table`（从典型图 W 表构建）给出首步推荐。

## 8. 位面参数
###  plane 与 W 表的关系

位面决定了 **尺度**（最大步数 $S_k$），尺度决定了 cheat 的资源封顶 $c_k^{\max} = S_k$（每步至多 1 cheat）。Reroll 不受步数约束（可单节点反复重投），封顶由玩家持有的 reroll 总量或 DP 计算上限（30）决定。三张典型图的实际步数：

| 位面 | 典型图 | 节点数 | 最长路径步数 $S_k$ |
|------|--------|--------|---------------------|
| 1 | `20260620_114926.png` | 13 | 8 |
| 2 | `20260620_115208.png` | 25 | 12 |
| 3 | `20260620_115639.png` | 8 | 5 |

资源封顶直接影响 future table 的计算：当 $c, r$ 超出某图封顶时，超出部分在该图的边际收益为 0，但可以留给后续图使用。

## 9. 关键假设与局限

| 假设 | 说明 |
|------|------|
| CD 线性可加 | $V = \text{cd} + W$，所有操作均为线性加减 |
| 效果等概率独立 | $e \sim U(1,6)$，与历史无关 |
| 列销毁确定性 | 仅取决于节点 $cx$ 坐标和 30px 列容差 |
| 资源边际递减 | DP 外推 $c>5, r>30$ 时边际收益为 0 |
| MC 统计噪声 | Q 表滑动窗口 200 样本，reroll 估值封顶以减轻噪声 |
| **W 表跨图复用** | 用典型图估计的 W 表适用于同一位面的其他地图实例（尺度相同但布局不同）。实际性能取决于典型图与实际图的相似度 |
| **资源分配独立性** | L3 联合分配假设各图 W 表可加（$W_1(c_1,r_1) + W_2(c_2,r_2)$），忽略图间 CD 累积的阈值效应（由 `thresholds` 参数补充处理） |
